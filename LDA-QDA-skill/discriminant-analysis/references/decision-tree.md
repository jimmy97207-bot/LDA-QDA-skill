
# LDA／QDA 分析決策規則

遇到資料問題、需要詢問使用者或判斷模型能否建立時閱讀。`lda_qda_pipeline.R` 的「資料檢查」表會先列出可能觸發下列規則的項目。

## 1. 確認分析設定

| 狀況                           | 處理方式                             |
| ------------------------------ | ------------------------------------ |
| 已指定 Y、X 與研究目的         | 進入資料檢查                         |
| 未指定 Y                       | 詢問分類欄位，不自行猜測             |
| 未指定 X                       | 用 `--plan` 提出 X 清單（數值欄位；名稱是編號、文字、常數的欄位自動排除；數值像編號的欄位標出來），請使用者確認或修改後才執行 |
| Y 只有一個類別，或不是分類任務 | 說明不適用，停止模型建立             |
| 存在重複測量、群組或時間順序（腳本偵測到重複編號、日期欄位，或使用者描述為多次紀錄） | 暫停（SKILL.md 關卡 C）：先確認研究單位；本版沒有分組驗證 |

## 2. 檢查資料問題

| 狀況                             | 處理方式                               |
| -------------------------------- | -------------------------------------- |
| 資料完整，欄位適用               | 自動進入 EDA                           |
| X 有缺失值                       | 先報告空格數量與分布，再詢問：以各訓練折中位數補值（`--impute median`），或停止。不刪除列、不在切分前補值 |
| Y 有缺失值                       | 停止並列出是哪幾列；Y 是類別答案，不補、不猜、不自行刪除，由使用者確認後再執行 |
| 有非有限數值（Inf、NaN）         | 停止並說明，需使用者確認資料來源 |
| 發現離群值                       | 標示與說明，不自動刪除                 |
| 發現常數欄位                     | 自動排除在 X 之外並說明 |
| 發現線性相依                     | 若導致 LDA、QDA 都不可估計，停止並說明哪些欄位相依（關卡 F），由使用者決定是否換一組 X |
| 疑似 ID 或結果發生後才取得的變數 | 名稱是編號才自動排除；數值像編號（全部不同的整數）保留並請使用者確認；說明洩漏疑慮；無法確認用途時詢問使用者 |
| 類別不平衡                       | 保留類別，以 Macro recall 為主要指標 |
| 某類少於 5 筆                    | 停止並說明（關卡 E）：分層 5-fold 無法執行；不減少折數、不合併或刪除類別 |

## 3. 診斷與模型可行性

先完成分組描述統計、適當圖形及可執行的假設診斷。

- Mardia’s test 與 Box’s M test 作為診斷資訊。
- 不使用「Box’s M 顯著就選 QDA」之類的單一判斷規則。
- 分別檢查 LDA 與 QDA 的可估計性。

| 模型狀態          | 下一步                                 |
| ----------------- | -------------------------------------- |
| LDA、QDA 皆可建立 | 以相同驗證切分比較                     |
| 僅 LDA 可建立     | 評估 LDA，說明 QDA 不可行原因          |
| 兩者皆不可建立    | 停止配適，提出需要使用者決定的處理選項 |

合併組內共變異數奇異時，每一類的組內共變異數也一定奇異，所以不會出現「只有 QDA 可建立」的情況。

不擅自改用其他分類方法。

## 4. 驗證過程的判斷

- 切分固定為分層 5-fold 重複 10 次，不依結果調整；觀測結構不符合（同一對象多筆）時暫停（關卡 C）。
- 每個訓練折重新估計所需的前處理與模型。
- 每折都檢查模型是否可以建立。
- 保存折別、隨機種子、設定及失敗原因。

若有驗證折失敗，不直接刪除失敗折後宣稱完成比較：該方法標為「驗證不完整」，不參加比較，只評估另一個方法。不為了讓模型跑得過而更改切分。

## 5. 模型建議與報告

選方法只依下方固定規則；報告另外呈現以下資訊供解讀：

- 各類別的預測表現與混淆矩陣。
- 10 次重複的範圍與勝出次數（穩定性）。
- 模型複雜度與研究解釋需求（例如 LDA 有判別軸可畫圖）。

選擇規則：分層 5-fold 重複 10 次，平均 Macro recall 較高者勝出；完全相同時選較簡單的 LDA。方法必須 10 次全部完成才參加比較，否則標為「驗證不完整」，只評估另一個方法。落後者也贏了不少次時，照規則選擇，但說明兩者表現接近。選定後用全部資料重新配適最終模型。
若結果不足以支持明確選擇，直接呈現不確定性。

報告寫明分數來自交叉驗證，不是獨立測試表現；本版沒有獨立測試集。
並列出實際完成、失敗與未執行的分析。
